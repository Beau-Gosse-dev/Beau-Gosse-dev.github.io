# Expansion-band stretcher 3D model

[Download band_stretcher.zip](https://raw.githubusercontent.com/Beau-Gosse-dev/Beau-Gosse-dev.github.io/main/downloads/band-stretcher/band_stretcher.zip)

Original ZIP from September 15, 2026, shared without modifying its contents.

The archive includes:

- drum.stl - main drum.
- slot_inserts_16-20mm.stl - two inserts of each size from 16 to 20 mm.
- expansion_band_stretcher.scad - editable OpenSCAD source.
- preview.png - assembly illustration.
- README.txt - dimensions, printing, assembly, and use instructions.
- mesh_check.json - mesh check results supplied with the model.

All model dimensions are in millimeters. The included instructions describe this as a prototype that has not been physically tested; read README.txt before printing or using it.
